# P-values

## Definition
P-value measures the probability of observing the data (or something more extreme) under the null hypothesis.

## Interpretation
- Small p-value (<0.05): Reject null hypothesis, predictor is statistically significant.
- Large p-value: Not enough evidence to reject null.

## Example
Coefficient(StoreTypeB) = -2.1, p = 0.001 → Strong evidence StoreTypeB affects Sales.
