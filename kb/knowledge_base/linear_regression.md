# Linear Regression

## Definition
Linear regression models the relationship between a dependent variable (Y) and one or more independent variables (X).

## Formula
Y = β₀ + β₁X₁ + β₂X₂ + ... + βnXn + ε

## Interpretation
- β coefficients represent the expected change in Y for a one-unit change in X, holding other variables constant.
- β₀ (Intercept) is the baseline value of Y when all X=0.

## Example
Model: Sales ~ Price + Promotion
If β₁ = -2.5 → For each unit increase in Price, Sales decrease by 2.5 units (keeping Promotion constant).
