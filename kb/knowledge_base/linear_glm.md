# Linear Regression and GLMs

## Linear Regression
- Models the relationship between a continuous dependent variable and one or more independent variables.
- Equation: y = β0 + β1x1 + ... + βnxn + ε

## Generalized Linear Models (GLMs)
- Extend linear regression to allow the dependent variable to follow distributions other than Gaussian.
- Examples:
  - Logistic regression (binary outcomes)
  - Poisson regression (count data)
  - Gamma regression (positive continuous data)
- Link functions connect the linear predictor to the expected value of the distribution.
