# Model Selection: AIC, BIC, LogLik

## AIC (Akaike Information Criterion)
- Trade-off between model fit and complexity.
- Lower AIC = better model.

## BIC (Bayesian Information Criterion)
- Similar to AIC but penalizes complexity more heavily.
- Useful for large samples.

## LogLik (Log-Likelihood)
- Higher log-likelihood = better model fit.
- Used for nested model comparison.
