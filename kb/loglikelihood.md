# Log-Likelihood

## Definition
Log-likelihood (logLik) measures how well the model fits the observed data.

## Formula
logLik = ln(Likelihood of data given parameters)

## Interpretation
- Higher logLik = better model fit.
- Used to compute AIC and BIC.

## Example
Model 1: logLik = -200
Model 2: logLik = -180
→ Model 2 fits better.
